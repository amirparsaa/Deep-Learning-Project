# Deep-Learning-Project

Developed and evaluated multiple object tracking algorithms, including DeepSORT, ByteTrack, and FairMOT, using Python. Implemented object detection models like
YOLO and Faster R-CNN to enhance tracking accuracy. Conducted data preprocessing and augmentation on datasets like SportsMOT for improved model performance. Assessed algorithms based on metrics such as MOTA, Precision, and IDF1. Proposed and implemented innovative improvements to address challenges like occlusion and scale variation. Demonstrated robust tracking in real-world video scenarios with performance visualizations.
